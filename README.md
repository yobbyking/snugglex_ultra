# SnuggleX Ultra

Deploy on Railway/Render/Heroku with `SESSION_ID` env var.

## Deploy
1. Pair at the SnuggleX Pair site → get session ID in your WhatsApp DM
2. Deploy this repo on Railway/Render
3. Set env var: `SESSION_ID` = `snugglex:~xxxxxxxxxxxx`
4. Bot connects and sends "CONNECTED ✅" message to your DM

## Features
- Menu, antilink, anticommands, .vv, .getpp
- promote/demote/antidemote/antipromote
- tagall, hidetag, kick, add, ginfo, link
- song, video, sticker, url, tts, translate
- ai, chatbot, 8ball, truth, dare, joke, quote
- calc, qr, uuid, pass, hash, base64, fliptext
- setpp, setbio, setname, setownername, block, unblock, pair
